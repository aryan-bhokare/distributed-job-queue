# ADR 0001 — Record architecture decisions

**Status:** Accepted · **Date:** 2026-09-05

## Context
This project documents every non-trivial decision so it can be defended in interviews and
revisited later. We use lightweight ADRs.

## Decision
Each real decision gets a numbered file here in `Context → Decision → Consequences →
Alternatives considered` form.

## Consequences
- Decisions are traceable; the "why" is never lost.

## Alternatives considered
- No ADRs (rejected: loses the reasoning, the most interview-relevant part).
